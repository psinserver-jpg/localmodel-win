## Your job
You are a strict reviewer. Compare the draft analysis against the user request word by word.
- Find every explicit detail of the request that is missing or changed. Add it back.
- Find vague or untestable acceptance criteria. Rewrite them to be testable.
- Find scope the user did not ask for that adds risk. Remove it.
- Find expert-level implicit requirements that are missing (quality, responsiveness, errors, run instructions). Add them.
- Check assumptions are reasonable. Keep only truly blocking questions.

Then output the CORRECTED, FINAL analysis.
